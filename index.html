minimind — Train a 64M-Parameter Transformer LLM from Scratch in Under 2 Hours

minimind is an end-to-end educational and production LLM training pipeline that builds a compact 64-million-parameter Transformer from raw text to chat deployment. It covers BPE tokenizer training, RoPE/SwiGLU pretraining, supervised fine-tuning (SFT), Direct Preference Optimization (DPO), and Mixture-of-Experts routing.

class MiniMindBlock(nn.Module):
    def __init__(self, args: LMConfig):
        super().__init__()
        self.attn_norm = RMSNorm(args.dim, eps=args.norm_eps)
        self.attn = GroupedQueryAttention(args)
        self.ffn_norm = RMSNorm(args.dim, eps=args.norm_eps)
        self.ffn = SwiGLUFFN(args.dim, args.hidden_dim)

    def forward(self, x, freqs_cos, freqs_sin, past_kv=None):
        h, kv = self.attn(self.attn_norm(x), freqs_cos, freqs_sin, past_kv)
        out = x + h
        return out + self.ffn(self.ffn_norm(out)), kv
